# UZAY-ZAMAN

Uzay, zaman ve evren hakkında temel bilgileri etkileşimli bir web arayüzüyle sunan eğitim amaçlı web projesi.

## Canlı Demo

[UZAY-ZAMAN web sitesini ziyaret et](https://halilbraim.github.io/UZAY-ZAMAN/)

## Proje Hakkında

Bu proje; uzay, zaman, evren ve bilimsel konulara ilgi duyan kullanıcıların temel bilgileri daha anlaşılır ve görsel bir şekilde keşfedebilmesi amacıyla geliştirilmiştir.

Proje geliştirilme aşamasındadır ve yeni konular, içerikler ve etkileşimli özellikler eklenmeye devam edecektir.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Dosya Yapısı

```text
UZAY-ZAMAN/
├── index.html
├── style.css
├── script.js
└── topicsData.js
```

## Özellikler

- Uzay ve zaman temalı kullanıcı arayüzü.
- Etkileşimli konu içerikleri.
- JavaScript ile dinamik içerik yönetimi.
- Responsive tasarım çalışmaları.
- GitHub Pages üzerinde canlı yayın.
- Bilimsel konuları sade ve anlaşılır biçimde sunma hedefi.

## Geliştirme Durumu

Proje şu anda geliştirme aşamasındadır.

Planlanan geliştirmeler:

- Yeni uzay ve bilim konuları eklemek.
- İçerik kartlarını geliştirmek.
- Mobil görünümü iyileştirmek.
- Daha fazla etkileşimli özellik eklemek.
- Animasyonları ve kullanıcı deneyimini geliştirmek.
- Bilimsel kaynaklar bölümü oluşturmak.

## Yerel Olarak Çalıştırma

Projeyi bilgisayarında çalıştırmak için:

```bash
git clone [https://github.com/Halilbraim/UZAY-ZAMAN.git](https://github.com/Halilbraim/UZAY-ZAMAN.git)
cd UZAY-ZAMAN
```

Daha sonra `index.html` dosyasını tarayıcıda açabilirsin.

VS Code kullanıyorsan Live Server eklentisiyle projeyi daha rahat çalıştırabilirsin.
